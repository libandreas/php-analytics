# PHP Analytics

Στατιστικά επισκεψιμότητας και διαγνωστικά για ιστοσελίδες PHP, με αποθήκευση σε CSV αντί για βάση δεδομένων.

## Τι κάνει

Τα content-9.php και content-9.js καταγράφουν clicks, αιτήματα σελίδων, ειδοποιήσεις και σφάλματα εφαρμογής. Ο πίνακας διαχείρισης προσφέρει φίλτρα ημερομηνίας και σελίδας, ταξινόμηση, σελιδοποίηση και στατιστικά ανά browser, λειτουργικό σύστημα, χώρα και γλώσσα.

Υποστηρίζει επίσης καταγραφή συμβάντων αδειών χρήσης και επιλογών παρόχου ή μοντέλου AI, όταν συνδεθεί με τις αντίστοιχες λειτουργίες της εφαρμογής.

## Ενσωμάτωση

Λειτουργεί ως πρόσθετο επίπεδο παρακολούθησης πάνω στην υπάρχουσα εφαρμογή PHP. Το JavaScript παρακολουθεί ενέργειες στον browser και ο PHP endpoint αποθηκεύει τα συμβάντα και εμφανίζει τις αναφορές.

Τοποθετήστε τα αρχεία στον φάκελο common/ και φορτώστε το content-9.js στις σελίδες που θέλετε να παρακολουθείτε. Αιτήματα και συμβάντα μπορούν να αποστέλλονται στον endpoint common/content-9.php. Η συμπερίληψη του content-9.php σε μια σελίδα προσθέτει τον σύνδεσμο διαχειριστή· δεν καταγράφει από μόνη της την επίσκεψη.

Η πρόσβαση στις αναφορές χρησιμοποιεί τον κοινό έλεγχο διαχειριστή. Η ανακατεύθυνση σύνδεσης απαιτεί το content-0.php και τη διαχείριση χρηστών του [PHP Content Manager](https://github.com/libandreas/php-content-manager) ή προσαρμογή στο σύστημα σύνδεσης της εγκατάστασης.

Απαιτούνται εγγράψιμο analytics.csv και φάκελος cache/ στη ρίζα της ιστοσελίδας. Ο εντοπισμός χώρας χρησιμοποιεί cURL, την υπηρεσία api.country.is και το συνοδευτικό cacert.pem. Τα αρχεία καταγραφής περιλαμβάνουν διευθύνσεις IP και πρέπει να αποκλείονται από δημόσια πρόσβαση.

## Αρχεία

- content-9.php: συλλογή συμβάντων και πίνακας διαχείρισης.
- content-9.js: καταγραφή ενεργειών και ειδοποιήσεων στον browser.
- content-9.css: εμφάνιση των αναφορών.
- functions.php και polyfills.php: κοινές λειτουργίες ενσωμάτωσης.

Δεν περιλαμβάνονται πραγματικές καταγραφές ή δεδομένα επισκεπτών.
